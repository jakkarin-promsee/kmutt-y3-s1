## 1.1 ขั้น 5–6 ขยาย: เลือก factor ยังไง

**กฎอ่านชื่อ: ตัวหน้า `/` = สิ่งที่อยากได้ · ตัวหลัง `/` = สิ่งที่มี** แล้วมันตัดกันเหมือนเศษส่วน —
$P \times (F/P) = F$ · $A \times (P/A) = P$ · **ถ้าคูณแล้วตัวอักษรไม่ตัดกัน = หยิบผิด**

| โจทย์พูดว่า | ใช้ |
| --- | --- |
| ก้อนเดียว จ่าย/รับ ณ ปีที่ `k` | `(P/F, i, k)` — ก้อนละครั้ง กี่ก้อนก็กี่ครั้ง |
| เท่ากันทุกปี ปี 1→n | `(P/A, i, n)` |
| เท่ากันทุกปี แต่อยากได้ค่าปลายทาง | `(F/A, i, n)` |
| มีเงินก้อนวันนี้ อยากรู้ว่าผ่อนปีละเท่าไหร่ | `(A/P, i, n)` |
| เพิ่ม/ลด **ปีละ G บาท** | `X(P/A,i,n) ± G(P/G,i,n)` ← **สองก้อน** |
| เพิ่ม/ลด **ปีละ g %** | สูตร $P_g$ ← **ก้อนเดียว** ไม่มีตาราง |
| `i` หรือ `n` ไม่มีในตาราง | สูตร > spreadsheet > interpolate *(interpolate อ่านสูงเกินจริงเสมอ)* |

## 1.2 กฎวางตำแหน่ง 4 ข้อ 🔑

1. `P/A`, `A/P` → **P อยู่ล่วงหน้า A ตัวแรก 1 งวด**
2. `F/A`, `A/F` → **F อยู่งวดเดียวกับ A ตัวสุดท้าย** (ไม่ใช่ถัดไปอีกงวด)
3. Arithmetic → **G เริ่มระหว่างงวด 1 กับ 2** ⇒ `P_G` ล่วงหน้าการเปลี่ยนแปลงแรก 2 งวด
   แต่ **`n` ที่ใส่ยังเป็น n ของทั้งชุด ไม่ใช่ n−1**
4. Geometric → $A_1$ อยู่ **งวดที่ 1** และ **อยู่ในสูตรแล้ว** ⇒ ห้ามบวก `P/A` ซ้ำ

> 🔑 ถ้า series ไม่ได้เริ่มที่ปี 1 (เช่นเริ่มปี 4) → `(P/A,i,n)` จะพา P ไปตกที่ **ปีที่ 3**
> ต้องเด้งต่อด้วย `(P/F,i,3)` อีกที **สองต่อ**

# ส่วนที่ 3 — สูตรและ trick

## 3.1 สูตรที่ต้องจำ (เมื่อตารางช่วยไม่ได้)

ตัวเต็มอยู่ใน [[Chapter+2+-+Engineering+Economy+Factors.pdf]]
*(อ่านผ่านแคช [[Chapter+2+-+Engineering+Economy+Factors]] — ต้นฉบับ `pdftotext` ออกมาเป็นขยะ)*

$$F = P(1+i)^n \qquad P = \frac{F}{(1+i)^n} \qquad
P/A = \frac{(1+i)^n - 1}{i(1+i)^n} \qquad F/A = \frac{(1+i)^n - 1}{i}$$

$$A/G = \frac{1}{i} - \frac{n}{(1+i)^n - 1} \qquad\qquad
\boxed{P/G = (A/G)\times(P/A)}\ \text{← formula sheet ไม่มี } P/G \text{ แบบ finite } n$$

**Geometric gradient** (ไม่มีตารางเด็ดขาด ต้องกดสูตรทุกครั้ง):

$$P_g = A_1\left[\frac{1 - \left(\frac{1+g}{1+i}\right)^{n}}{i-g}\right] \quad (g \neq i)
\qquad\qquad P_g = \frac{A_1\,n}{1+i} \quad (g = i)$$

- $A_1$ = เงินของ **ปีที่ 1** · $P_g$ ตกที่ t = 0 (ล่วงหน้า $A_1$ หนึ่งงวด เหมือน `P/A`)
- `g` ติดลบ → แทนค่าติดลบลงไปตรง ๆ ได้เลย
- `g > i` → ใช้สูตรเดิม ตัวเศษกับตัวส่วนติดลบทั้งคู่ หักล้างกันเอง
- อยากได้ `A` → ไม่มีทางตรง ต้องเด้งสองต่อ: $A = P_g \times (A/P, i, n)$

## 3.2 Trick ที่ประหยัดเวลาและกันพลาด

| Trick | ทำไม |
| --- | --- |
| **เกิดปีเดียวกัน = รวมก่อนคูณ** เช่น (−7,800,000 + 780,000) × `P/F` | เหลือ factor ตัวเดียว ลดจุดพลาด |
| **แตกก้อนตั้งแต่แรก** | เปลี่ยนสมมติฐาน 1 ข้อ = แก้แค่บรรทัดเดียว |
| **ตรวจด้วยผลรวมเงินสดดิบ** โจทย์นี้ = 25,945,000 ฿ | PW = 51% ของเงินสดจริง สมเหตุสมผลที่ i สูง |
| **แปลงเป็น AW เสมอเมื่อจะเทียบทางเลือก** | ค่าเช่า/ค่าบริการเขาคิดกันเป็นรายปี |
| **ตัวเลขที่ไม่ได้ใช้ = อ่านโจทย์ผิด** | ข้อนี้ตัวเลข 25% คือกุญแจทั้งข้อ |
| **ไม่มี 11%, 13%, 14%, 16%, 17%, 19% ในตาราง** | เจอ i พวกนี้ = ต้องกดสูตร ไม่ต้องเสียเวลาพลิกหา |
